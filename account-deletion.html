선셋레코드 계정 및 데이터 삭제 안내

  • 앱 이름: 선셋레코드 (Sunset Record)
  • 개발자: 이승정
  • 패키지: com.sunsetrecord.app

방법 1. 앱에서 바로 삭제 (권장)

  1. 앱을 열고 로그인합니다.
  2. 아래 탭에서 "설정"을 엽니다.
  3. 화면 맨 아래의 "계정 삭제"를 누릅니다.
  4. 안내를 읽고 "위 내용을 확인했고, 계정과 모든 기록을 삭제하는 데 동의해요"에 체크한 뒤 "계정 삭제" 버튼을 누릅니다.

삭제는 즉시 처리되며 되돌릴 수 없습니다. 인터넷 연결이 필요합니다. 삭제에 실패하면 안내가 나오고 계정은 그대로 남습니다(일부만 삭제되지 않습니다).

방법 2. 앱을 열 수 없을 때 이메일로 요청

앱을 지웠거나, 기기를 잃어버렸거나, 로그인할 수 없는 경우입니다.

  • 받는 사람: sunsetrecord.app@gmail.com
  • 제목: [선셋레코드] 계정 삭제 요청
  • 본문에 적을 내용:
    1. 앱에 로그인할 때 쓴 이메일 주소(Google 또는 Apple 계정)
    2. 로그인 수단(Google 또는 Apple)
    3. 삭제를 요청한다는 문장
  • 반드시 앱에 로그인한 그 이메일 계정으로 보내 주세요. 다른 주소에서 보낸 경우 본인 확인을 위해 추가 확인을 요청할 수 있습니다. 비밀번호나 인증 코드는 보내지 마세요.
  • 처리 기간: 요청을 받은 뒤 영업일 기준 7일 이내에 삭제하고, 완료되면 답장으로 알립니다.

삭제되는 데이터

  • 로그인 계정 정보(이메일, 계정 식별자, 로그인 수단 정보, 로그인 수단이 제공한 이름·프로필 사진 주소)
  • 프로필(가입 시각)
  • 작성한 모든 기록(작품 정보, 감상 상태, 별점, 감상평, 본 날짜, 생성·수정 시각)
  • 이 기기에 저장된 기록 캐시와 로그인 세션(앱에서 삭제할 때 자동으로 지워집니다. 이메일로 요청한 경우 앱을 지우면 함께 사라집니다.)
  • Google 로그인의 경우 앱에 부여한 Google 계정 접근 권한도 해제합니다(앱에서 삭제할 때). 이메일로 요청한 경우 Google 계정의 연결된 앱 페이지(myaccount.google.com/linkedapps)에서 선셋레코드를 선택하고 "액세스 권한 삭제(Remove access)"를 눌러 직접 해제할 수 있습니다.

삭제 후 같은 계정으로 다시 로그인하면 기록이 없는 새 계정으로 시작합니다. 다른 기기에 로그인된 상태는 다음 앱 실행 때 자동으로 로그아웃됩니다.

삭제 후 보관하는 데이터

  • 법령에 따라 보관해야 하는 개인정보는 없습니다.
  • 백업에 남는 데이터는 없습니다(현재 자동 백업을 사용하지 않습니다).
  • 서비스 제공자(Supabase)의 접속 기록(접속 시각, IP 주소 등)은 서비스 제공자의 정책에 따라 일정 기간 보관 후 자동 삭제됩니다. 이 기록은 계정·기록 데이터와 별개이며 운영자가 임의로 삭제할 수 없습니다.

부분 삭제

이 앱은 계정을 유지한 채 일부 데이터만 지우는 기능을 별도로 제공하지 않습니다. 기록은 앱의 "내 기록" 탭에서 하나씩 삭제할 수 있고, 계정 전체를 지우려면 위 방법을 쓰세요.
